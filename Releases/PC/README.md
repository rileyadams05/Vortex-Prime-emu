# Vortex Prime Desktop App Downloads

These files are desktop app wrappers for Vortex Prime.

The app opens the live Vortex Prime website:

https://vortex-prime-emu.com/

Because the app loads the live website, website updates happen automatically. You only need a new desktop app download when the wrapper app itself changes.

## Supported Systems

Vortex Prime desktop builds are provided for Windows, Linux, and macOS, so it should work on most modern computers.

Windows and Linux builds have been tested locally. macOS builds are provided, but I cannot personally test them because I do not have a Mac.

## Windows

Open the `Windows` folder and choose the folder that matches your computer:

- `x64` - most modern Windows computers
- `x86` - older 32-bit Windows computers
- `x32` - same type of 32-bit build as x86, included for clarity
- `ARM64` - Windows on ARM devices

Download and run the setup `.exe` file from the correct folder.

## Linux

Open the `Linux` folder and choose the folder that matches your computer:

- `x64` - most modern Linux computers
- `ARM64` - ARM Linux devices
- `x86` - older 32-bit Linux computers

Download the `.AppImage` file from the correct folder, make it executable if needed, then run it.

## macOS

Open the `Mac OS` folder and choose the folder that matches your Mac:

- `Intel` - older Intel-based Macs
- `Apple-Silicon` - M1, M2, M3, M4, and newer Apple Silicon Macs

Download the `.dmg` file from the correct folder.

Note: macOS builds are generated using GitHub Actions macOS runners. They have not been personally tested on a physical Mac.
