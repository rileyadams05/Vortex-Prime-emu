How to Install Themes

1

Copy Code

Find a theme you like and copy its code

2

Open Store in App

Go to the Store tab in Vortex Prime

3

Paste & Enter

Paste the code and press Enter to download

4

Enable Theme

Move from Disabled to Play to activate

Keyboard shortcuts: Ctrl+P Move to Play Ctrl+D Move to Disabled
