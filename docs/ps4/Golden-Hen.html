Vortex Prime PS4 GoldHEN Selector

Enter your PS4 firmware to see compatible GoldHEN builds hosted from Vortex Prime. The recommended option is the best first choice.

How to use

Type your PS4 firmware and press Enter. Example: 9.00

Commands (type then press Enter):
run — run the recommended GoldHEN exploit
cache — optional cache for faster/offline loading
clear cache — reset cached host files

Caching is optional. You do not need to cache before running.
