Streamz Support

Use the official Discord server for the fastest Streamz help.

Bugs and technical issues

Post reproducible bugs in the public Discord Bugs channel. Include what happened, your Streamz version, your operating system, what you already tried, and any screenshot or log that helps explain the issue.

The Streamz bot may reply with automated troubleshooting. If automated troubleshooting is unavailable, DM the Streamz bot and use /contact-support for private assistance.

Join the Streamz Discord

Private support

For account-specific app help, directly message the Streamz bot in Discord and run /contact-support. Do not post private payment, account, activation-code, or personal details in public channels.

Staff replies are sent through the official Streamz bot. Social media messages are not guaranteed support channels, and email support may be slower.

Expired activation code

If your Streamz Pro activation code expired before you used it, directly message the Streamz bot and run /code-expired with your original activation-pass PDF attached.

Do not use screenshots, photos, PNGs, JPGs, or recreated PDFs for expired-code review.
