How to publish a package
  1. Click + Add ZIP and fill in the package details below.
  2. Enter the store code, title, description, creator, and any download link.
  3. Click Save Package File when you are done editing.
  4. Commit the saved file to GitHub — the store updates within ~60 seconds.
Advanced: the saved file is docs/store/themes.json in the repository.
