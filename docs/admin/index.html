Publish Store Packages

Sign in with GitHub (public or admin) to create pull requests that add new packages to the Vortex Prime store. Maintainers review and merge submissions so the catalogue stays secure while remaining open source.

Open community uploads. Anyone with a GitHub account can submit packages. Your changes will enter review before going live.

Before you submit

  • 1

    Collect your assets

    Have the icon, preview image, and either a ZIP package or an external download link ready.

  • 2

    Complete the fields

    Provide the package title, description, creator credit, tags, and store code used by the app.

  • 3

    Review the preview card

    Use the live preview to confirm how the package appears on the public store before publishing.

Provide either a ZIP upload or an external download link. Packages without a download source cannot be published.

Community submissions land in a GitHub pull request for maintainer approval. No credentials are stored in the browser.
