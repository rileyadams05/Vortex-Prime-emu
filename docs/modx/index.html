Publish a cheat table to ModX

Choose the game, enter the executable ModX should recognise, then upload the `.CT` file. The website passes it securely to the backend and the file is committed to the separate ModX GitHub repository.

Choose one .CT file, up to 8 MB

Where the file goes

  • The `.CT` file is not saved in website storage.
  • Cloudflare validates and forwards it.
  • GitHub stores it in the ModX repository.
  • ModX records a pending catalogue entry for review.
