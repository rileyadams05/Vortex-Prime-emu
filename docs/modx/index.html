    How publishing works

    Each step unlocks only after the previous step is complete.

    1. Select the game’s executable. Mod X fingerprints it locally; the file is not uploaded.
    2. In Mod X DEV Mode, import the CT locally and build the finished .modxtrainer file. Editable source files remain on your computer.
    3. Attach only that finished build to a public GitHub Release, then paste the full Release URL here.
    4. Choose who will maintain the one canonical repository through GitHub.
    5. Mod X verifies the game, Release, documentation and finished build without executing it.
    6. Confirm offline/single-player intent, then publish. Mod X stores metadata only, downloads come directly from GitHub, and newer Releases are detected automatically.
