How publishing works

  • The game executable is fingerprinted locally and is never uploaded.
  • The `.CT` file is not saved in website storage.
  • Cloudflare performs automatic technical and security checks.
  • Valid tables are published immediately from the separate ModX repository.
  • Community reports can trigger an immediate takedown.
  • All tables are for offline or single-player use only.
