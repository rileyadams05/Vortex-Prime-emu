How a pull request works

  1. Fork the Vortex Prime repository on GitHub and add listing metadata to docs/modx/catalogue.json.
  2. Link to the creator's public GitHub project or Release. Keep table files and builds in their creator-owned location.
  3. Open a pull request. Maintainers review attribution, compatibility details, and permissions before merging.
  4. After merge, the website reads the reviewed metadata directly from this repository.

This website stores catalogue text in GitHub and does not accept file uploads. Do not include binaries or third-party files without redistribution permission.
