How publishing works

  • Upload the game’s executable so ModX can identify the game.
  • Host your Cheat Engine table in a public GitHub repository.
  • Paste the GitHub repository or table link here.
  • Include supported versions, storefronts and instructions in your GitHub README.
  • Choose whether you’ll maintain the listing yourself or allow reviewed community maintenance.
  • ModX catalogues the table. The actual table remains hosted on GitHub.
