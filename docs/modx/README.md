# Publishing a ModX community table

ModX is a catalogue. It does not accept or permanently store Cheat Engine `.CT` files.

Keep the canonical table in a public GitHub repository and submit that repository URL (or a direct GitHub `blob` URL to a `.CT` file) through the ModX publishing page.

Your repository README should document:

- the supported game and executable;
- supported game versions and builds;
- relevant storefronts or services (Steam, Epic, GOG, Xbox, and others);
- features and cheats;
- requirements and installation instructions;
- known issues and a changelog; and
- whether you plan to support other versions or platforms.

If community maintenance is enabled, contributors propose a GitHub fork, repository, or commit through ModX. A proposal must be reviewed before it becomes the current source. The original author and original repository remain attributed on the listing.
