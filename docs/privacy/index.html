Privacy Policy

Last updated: 13 July 2026

Information We Use

For historical Streamz Pro purchases, records may include account identifiers, Google subject and email, Discord verification identifiers, checkout contact information, Stripe payment or customer identifiers, entitlement status, payment amount, currency, timestamps, and security records. Streamz Pro sales and new activations have been retired. Existing payment and account records have not been deleted by this change.

Payment Data

Stripe processes payment details. Vortex Prime does not receive or store raw card numbers, wallet credentials, CVC values, or bank details.

Discord Verification

Discord is used to claim a paid Streamz Pro verification session. The human-readable verification code and website token are temporary, single-use, and stored by Vortex Prime only as secure hashes.

Google Account Linking

The Streamz Pro licence is linked to Google's stable subject identifier after activation. Changing a visible email address does not move ownership of the licence.

Data Sharing

Vortex Prime uses Cloudflare and GitHub Pages to host the website, Stripe for historical payments, Discord for historical verification interactions, and Google for sign-in. The public community catalogue is a static file hosted with the website and does not use an external storage service. Some existing account, Streamz, and ModX API operations still use a Google Drive-backed database. These operations support the existing account and project features and are separate from public catalogue downloads. We do not sell historical Streamz Pro activation data.

Contact

If you need help with Streamz Pro account access or privacy questions, contact Vortex Prime support through the official website or Discord server.
