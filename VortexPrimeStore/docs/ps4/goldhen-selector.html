GoldHEN Firmware Compatibility

Enter your PS4 system software version to see the GoldHEN options that exist in the local Vortex Prime browser-host files used by this site.

How to use
Enter your PS4 firmware, then press Enter. Example: 9.00.

After checking compatibility, type:
run - run the recommended GoldHEN exploit
cache - optional: cache the host for faster/offline loading
clear cache - reset cached host files

Caching is optional. You do not need to cache before running the exploit.

Sort
Start by entering your firmware. We’ll highlight the latest compatible GoldHEN builds once you search.
