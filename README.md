## 📋 What is Vortex Prime?

Vortex Prime is a **personal project** aiming to create a unified emulator frontend with:
- Xbox 360-style "Blades" and NXE dashboard interface
- Integration with Xenia (Xbox 360 emulator)
- Unified achievement tracking via Exophase
- Modern gamepad navigation

## 🛠️ Development Setup

This project uses:
- **Tauri 2.0** (Rust backend)
- **React** (Frontend)
- **Python** (Backend API)

```bash
# Clone the repo
git clone https://github.com/rileyadams05/Vortex-Prime-emu.git

# Install dependencies
cd frontend && npm install
cd ../backend && pip install -r requirements.txt

# Run in development
npm run tauri dev
```
